# Campus Compute: Intelligent Job Scheduling and Resource Management

## Prerequisites
- Linux/Ubuntu or WSL Ubuntu environment.
- GCC compiler and Make build tools.

## Build Instructions
Run the following command in the terminal to compile the project:
`make`

## Execution Commands
Run the compiled executable:
`./campus_compute`

## Cleanup Instructions
To clean up generated files and executables, run:
`make clean`
